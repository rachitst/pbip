# Finora v1.2.1 release notes

Tagged `v1.2.1` on 21 November 2026 from `main` and deployed through the pipeline; see the
[GitHub release](https://github.com/rachitst/pbip/releases/tag/v1.2.1) and [`CHANGELOG.md`](../../CHANGELOG.md).

## In plain language

- **v1.2.0 reaches the live site.** The automatic check after the v1.2.0 deployment still looked for the old name
  "PBIP" on the front page, did not find it, and put the previous version back, as it is designed to. The check
  now looks for "Finora", and this release went live.
- **Two buttons read the same as they sound.** For people who use voice control or a screen reader, the assistant
  button is now called exactly what it shows, "Ask Finora", and the fraud lab's buttons show "Run F1" to "Run F6".

No database migration, no configuration change.
