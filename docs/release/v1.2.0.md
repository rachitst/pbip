# Finora v1.2.0 release notes

Tagged `v1.2.0` on 21 November 2026 from `main`; the tagged commit and its checks are listed on the
[GitHub release](https://github.com/rachitst/pbip/releases/tag/v1.2.0). The full list of changes is in
[`CHANGELOG.md`](../../CHANGELOG.md); the design work, every test changed and every backend file whose text changed
are in [`docs/design/ui-redesign-progress.md`](../design/ui-redesign-progress.md).

## In plain language

- **A new name: Finora.** The bank is now called Finora ("Smart personal banking"), and the assistant is
  **Ask Finora**. It has its own logo. The project's code and repository keep the name PBIP.
- **A new look on every page.** Cleaner and calmer: white and soft-grey pages, navy text, one teal highlight, clear
  colours for success, warnings and problems, a modern typeface and a side menu with icons. It starts in the light
  theme; the dark theme is still one click away.
- **A front page.** Visitors who are not signed in see what Finora does, with real screenshots, and can sign in or
  open an account from the same page. It says plainly that this is a simulated bank built for a student capstone
  project and that no real money moves.
- **Nothing else changes.** Accounts, payments, fraud checks, the assistant's answers and the staff tools work exactly
  as in v1.1.4; only how they look and the product name changed.

## Upgrade notes

- No database migration (the schema stays at `0031`) and no configuration change.
- Authenticator apps enrolled before this release keep their old "PBIP" label; their codes still work. New
  enrolments show "Finora".
- Statements generated from now on carry the Finora header; the download file name keeps `pbip-statement-...`.
