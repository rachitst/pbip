# PBIP v1.1.4 release notes

Tagged `v1.1.4` on 8 November 2026 from `main`; the tagged commit and its checks are listed on the
[GitHub release](https://github.com/rachitst/pbip/releases/tag/v1.1.4). The full list of changes is in
[`CHANGELOG.md`](../../CHANGELOG.md).

## In plain language

- **A fix to v1.1.3's smoother releases.** When v1.1.3 was released, one request still stalled at the moment an old
  copy of the API was switched off: the web server briefly tried to reach a copy that was already gone. It now
  notices that within a second and asks another copy instead, and it learns about switched-off copies sooner.

Nothing changes for customers' data or money movement.

## Upgrade notes

- No database migration (the schema stays at `0031`).
- The new nginx setting takes effect once this release's `web` container runs, so the deploy that installs v1.1.4
  itself still uses v1.1.3's nginx.
