# Finora v1.2.2 release notes

Tagged `v1.2.2` on 21 November 2026 from `main` and deployed through the pipeline; see the
[GitHub release](https://github.com/rachitst/pbip/releases/tag/v1.2.2) and [`CHANGELOG.md`](../../CHANGELOG.md).

## In plain language

- **Loan offers are easy to read again.** On the accounts page, a recommended loan's "You could borrow" amounts now
  sit under their label instead of breaking across many short lines.
- **The user manual shows the new Finora screens.**
- **The walkthrough's subtitles line up with the picture** for the whole video.

No database migration, no configuration change.
